# Kyko Parfums — frontend

Next.js 16 (App Router) + Tailwind CSS 4. Запуск и описание проекта — в [корневом README](../README.md).

```bash
npm install
npm run dev      # http://localhost:3000, /api и /media проксируются на BACKEND_URL (по умолчанию http://localhost:8000)
npm run lint
npm run build
```
