# Kyko Parfums — мобильное приложение

Приложение для iOS и Android: тот же магазин, что и сайт, с теми же ценами, акциями и заказами,
а для сотрудников — вся админка сайта. Работает через API сайта (`<сайт>/api`), backend не
меняется.

|                |                                                                                           |
| -------------- | ----------------------------------------------------------------------------------------- |
| Стек           | Expo SDK 58 (React Native 0.88, React 19), TypeScript, Expo Router                        |
| Данные         | TanStack Query (кэш и повторы), `expo-secure-store` для токенов, AsyncStorage для корзины |
| Шрифты и стиль | Cormorant Garamond + Manrope, палитра сайта (`src/theme.ts`)                              |
| Сборка в сторы | EAS Build / EAS Submit, Mac не нужен                                                      |

## Что умеет

- **Главная**: баннеры акций (листаются сами), «Для магазинов и салонов», «Акции», «Новые
  поступления», бренды, связь через WhatsApp / Telegram / Instagram.
- **Каталог**: поиск по мере ввода, фильтры (пол, бренд, группа, тип, цена, акции, новинки),
  5 сортировок, подгрузка при прокрутке, обновление жестом вниз.
- **Карточка товара**: фото объёма, «Товар / Тестер», объёмы с ценами, цена по роли покупателя,
  акция с датой окончания, цены опта и крупного опта (оптовикам), «Ваша следующая цена»,
  пирамида нот, «Поделиться», «Спросить в WhatsApp», кнопка «В корзину» всегда под рукой.
- **Избранное** (сердечко): хранится на телефоне, цены всегда свежие.
- **Корзина**: цены считает сервер (`/cart/quote`), подсказки до оптового порога, выгода,
  «На крупном опте этот заказ стоил бы…».
- **Оформление**: контакты подставляются из профиля, заказ уходит менеджеру в Telegram, как с
  сайта.
- **Профиль**: статус и условия, мои заказы (статус, состав, история, отмена нового заказа,
  возвраты), личные данные, заявка на опт / крупный опт, смена пароля, политика
  конфиденциальности, выход и удаление аккаунта.
- **₸ / $**: переключатель на главной и в профиле, курс берётся с сайта. Оплата и заказы — в
  тенге.

Восстановление пароля: приложение просит сервер прислать письмо, новый пароль задаётся по
ссылке на сайте.

## Админка в приложении

Администратор, кассир и сотрудник склада после входа видят вкладку **«Админка»**; покупатели её
не видят. Разделы те же, что на сайте в `/admin`, и открыты по ролям, как там (`src/lib/staff.ts`
повторяет `frontend/src/lib/staff.ts`; права всё равно проверяет сервер):

| Раздел                  | Кто              | Что умеет                                                                                                                                                  |
| ----------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обзор                   | владелец         | выручка и маржа, заказы по статусам, пользователи по ролям                                                                                                 |
| Касса                   | владелец, кассир | продажа в магазине: сканер камерой или поиск, покупатель, уровень цен, скидка, оплата, себестоимость по кнопке                                             |
| Заказы и продажи        | все              | фильтры, статусы, состав, правка до доставки, возвраты, сборка сканером, накладная Excel                                                                   |
| Приёмка, Инвентаризация | владелец, склад  | документы со сканером, незнакомый штрихкод привязывается к товару на месте                                                                                 |
| Товары                  | владелец         | фильтры и экспорт в Excel, карточка: фото с камеры или из галереи, объёмы, цены, наценки, себестоимость, цены поставщиков, штрихкоды, история цен и склада |
| Акции, Бренды           | владелец         | баннер, скидка, даты, на что действует; логотипы брендов                                                                                                   |
| Пользователи            | владелец         | заявки на опт, роли, блокировка, новые сотрудники                                                                                                          |
| Импорт Excel            | владелец         | файл с телефона, проверка и импорт, шаблон и весь каталог                                                                                                  |
| Поставщики              | владелец         | прайс: проверка, привязка строк, применение; сопоставление в Excel                                                                                         |
| Настройки               | владелец         | пороги и скидки, курс доллара, получатели в Telegram                                                                                                       |

Сканер штрихкодов — камера телефона (`expo-camera`); в поле можно и вводить код, и сканировать
ручным сканером. Скачанные файлы (накладная, экспорт, шаблон) открываются в меню «Поделиться»:
сохранить в «Файлы», отправить в WhatsApp. Камера, галерея и выбор файлов работают в собранном
приложении и в Expo Go.

## Запуск на своём телефоне

Нужны Node.js 22 и приложение **Expo Go** на телефоне (App Store / Google Play).

```bash
cd mobile
npm ci
npx expo start
```

Отсканируйте QR-код камерой (iPhone) или в Expo Go (Android). По умолчанию приложение работает
с живым магазином на сервере в Казахстане, пока по временному адресу
`https://89-126-205-132.sslip.io` (`src/lib/config.ts`).

Чтобы работать с локальным сервером, запустите сайт (`frontend`, `npm run dev`) и укажите адрес
компьютера в сети, например:

```bash
EXPO_PUBLIC_SITE_URL=http://192.168.1.20:3000 npx expo start
```

`npx expo start --web` открывает то же приложение в браузере: удобно для быстрой проверки.
Тогда backend должен разрешать адрес Expo в `CORS_ORIGINS` (`http://localhost:8081`).

## Уведомления о заказах

Покупатель получает уведомление, когда менеджер переводит его заказ в «В обработке»,
«Отправлен», «Доставлен» или «Отменён»; нажатие открывает заказ (`src/lib/notifications.ts`,
backend — `services/push.py`). Разрешение приложение спрашивает после первого заказа или в
профиле («Уведомления о заказах»).

Проверить можно только на настоящем телефоне в собранном приложении: в симуляторе и в Expo Go
на Android уведомления не приходят. Тестовая сборка: `npx eas-cli@latest build --profile preview
--platform android` (APK по ссылке). Для iPhone при первой сборке EAS сам создаст ключ для
уведомлений Apple (нужен аккаунт Apple Developer). Адрес для уведомлений привязан к проекту
Expo `1be8691a-…` из `app.json` (`extra.eas.projectId`).

## Публикация в App Store и Google Play

Сборка идёт в облаке Expo (EAS), Mac и Android Studio не нужны.

1. Аккаунты: [expo.dev](https://expo.dev) (бесплатно), Apple Developer Program (99 $ в год),
   Google Play Console (25 $ один раз).
2. Один раз привяжите проект: `npx eas-cli@latest init` (впишет `extra.eas.projectId` в
   `app.json`).
3. Тестовая сборка для своих: `npx eas-cli@latest build --profile preview --platform android`
   даёт APK по ссылке; для iPhone — `--platform ios` (ad hoc, устройство регистрируется в
   процессе).
4. Сборка для сторов: `npx eas-cli@latest build --profile production --platform all`, затем
   `npx eas-cli@latest submit --platform ios` и `--platform android`. Ключи подписи EAS создаст
   и сохранит сам.
5. **До первой сборки для сторов** купите домен и задайте его в `eas.json` в профиле
   `production`: `"env": { "EXPO_PUBLIC_SITE_URL": "https://ваш-домен" }`. Адрес зашит в
   сборку: временный `…sslip.io` меняется вместе с IP сервера, и установленные приложения с ним
   перестанут работать. Тестовые сборки (`preview`) пока ходят на временный адрес.

Идентификаторы приложения: `kz.kyko.parfums` (iOS bundle id и Android package) — меняются
в `app.json` только до первой публикации. Иконка и заставка — в `assets/` (логотип «K» сайта).

Перед подачей в сторы:

- **Политика конфиденциальности** — страница `/privacy` на сайте; её ссылку вписывают в App
  Store Connect и Google Play Console. Реквизиты продавца берутся из `frontend/src/lib/legal.ts`.
- **Удаление аккаунта** (требование Apple) уже есть: Профиль → Удалить аккаунт.
- Скриншоты и описание для витрины.

## Устройство

```
src/
  app/                  # экраны (Expo Router: файл = экран)
    (tabs)/             # Главная, Каталог, Избранное, Корзина, Профиль, Админка (сотрудникам)
    admin/              # разделы админки: overview, pos, orders/, receipts/, counts/, products/, …
    product/[id].tsx    # карточка товара
    collection.tsx      # часть каталога: бренд, акция, новинки
    checkout.tsx, orders/, login.tsx, register.tsx, profile.tsx, wholesale.tsx, …
  components/           # ui (кнопки, поля, карточки), product, catalog, shop
    admin/              # сканер (поле + камера), формы и панели админки
  lib/
    api.ts              # запросы к /api, токены в Keychain/Keystore, автообновление токена
    auth.tsx            # вход, регистрация, профиль; смена роли сбрасывает кэш цен
    cart.tsx            # корзина на телефоне
    favorites.tsx       # избранное на телефоне
    currency.tsx        # ₸ / $
    queries.ts          # хуки TanStack Query: каталог, корзина
    types.ts, format.ts # те же типы и тексты, что на сайте
    admin-types.ts      # типы админского API (как в frontend/src/lib/types.ts)
    staff.ts            # роли сотрудников и их разделы
    files.ts            # фото и Excel с телефона, «Поделиться» скачанным файлом
  theme.ts              # цвета и шрифты сайта
```

Цены всегда считает сервер: приложение показывает то, что вернул API для роли покупателя, и
никогда не считает скидки само. Когда роль меняется (вход, выход, админ одобрил опт), весь
кэш запросов сбрасывается и цены загружаются заново.
